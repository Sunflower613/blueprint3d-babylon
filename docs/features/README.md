# 花花家园：全功能介绍与防呆呆手册

欢迎使用 **花花家园 全景家装设计系统**！本指南旨在帮助您从零开始，逐步掌握如何使用这套集 2D 平面绘制与 3D 高真实感渲染于一体的专业级户型设计系统。

---

## 📂 指南章节目录

为了方便您快速检索和系统学习，我们将手册拆分为以下五个核心使用场景模块：

1. **[项目管理与文件导出](01_file_and_system.md)**：
   掌握项目的新建、保存、本地与自动备份恢复，以及多格式文件（JSON, ZIP 资源包, 工业级 CAD 图纸 DXF, 3D 打印水密 3MF）的导出。
2. **[户型绘制与硬装搭建](02_structure_design.md)**：
   学习 2D 画墙、智能网格吸附、自动封闭面积生成，以及各种异形门窗、楼梯、智能开口栅栏的快速摆放与微调。
3. **[材质美化与表面涂刷](03_material_paint.md)**：
   学会使用取色吸管、油漆桶进行空间感应涂刷，以及上传自定义材质贴图并开启智能防拉伸（UV 平铺）补偿。
4. **[软装布置与智能家电](04_furniture_arrangement.md)**：
   了解物品的“重力感应式表面吸附”、格子柜一键智能填书，以及电器开关开启后触发的视听特效与物理动画联动。
5. **[视角漫游与高级渲染](05_view_and_render.md)**：
   体验第一人称 WASD 漫游与隐形胶囊防穿墙检测，探索右键快捷隐藏 pick 代理，以及多级镜面反射和探针视差纠正对齐技术。

## ⌨️ 快捷键速查表

在设计器中，熟练配合快捷键能成倍提升您的设计效率。以下是核心功能的快捷操作一览：

| 快捷键 | 对应功能场景 | 操控状态说明 |
| --- | --- | --- |
| **Space (空格)** | 选择模式 | 默认鼠标指针，用于选中房间、墙体或家具，在右侧编辑属性。 |
| **V** | 查看模式 | 抓手状态，用于拖拽并环顾 2D 平面画布，不会误触选中物体。 |
| **L** | 画墙模式 | 2D 视图下通过点击顶点绘制物理墙壁。 |
| **E** | 删墙模式 | 激活橡皮擦光标，点击任意一段墙壁即可将其快速拆除。 |
| **I** | 取色吸管 | 穿透复杂家具，精准提取鼠标指针指向的组件材质。 |
| **B** | 材质刷 | 将当前材质粉刷在鼠标点击的单个家具/组件表面。 |
| **G** | 智能油漆桶 | 房间级大面积粉刷，或一键同步同规格同类家具的材质。 |
| **C** | 材质橡皮擦 | 擦除选定表面上的自定义材质，使其还原为系统出厂底色。 |
| **Ctrl + Z** | 撤销 (Undo) | 回溯至上一步操作，系统历史栈深度支持 **80 步**。 |
| **Ctrl + Y** | 重做 (Redo) | 向前重做被撤销的设计步骤。 |
| **Ctrl + S** | 快速保存 | 手动覆写当前本地项目数据。 |
| **F12** | 拍照 📷 | 捕获当前 3D 视口中的超高清实景效果图（无 UI 遮挡）。 |
