# Blueprint3D-Babylon 测试计划与需求履历更新目录 (`docs/updates`)

本目录收录了 Blueprint3D-Babylon 项目的全量测试验证计划与 Bug 反馈记录。

## 📁 目录文件索引

- **`3D_Design_Software_Full_Test_Plan_V4.xlsx`**: **[当前最新]** 全量测试验证与迭代计划表格（包含 8 大阶段、73 项全量测试用例）。
- **`bug-[日期].txt`**: 原始 Bug 反馈与需求清单记录文件（Source 1 ~ Source 6）。

## V4 测试计划摘要

V4 测试计划共包含 73 项闭环用例，按 8 个阶段组织：

1. 核心架构重构与移动端兼容（V4-01 ~ V4-05）
2. 空间几何、拓扑编辑与墙体缝合（V4-06 ~ V4-12、V4-58、V4-67）
3. 门窗系统（V4-13 ~ V4-19）
4. 家具物理、吸附对齐与水效交互（V4-20 ~ V4-25、V4-47、V4-50、V4-51、V4-53、V4-59、V4-60、V4-70）
5. 材质、渲染、光照与着色器（V4-26 ~ V4-31、V4-52、V4-56、V4-63、V4-64、V4-68、V4-73）
6. 家具与装饰资源库（V4-32 ~ V4-37、V4-48、V4-49、V4-57、V4-61、V4-62、V4-65、V4-69、V4-71、V4-72）
7. 交互体验、AI Skill 与导出引擎（V4-38 ~ V4-43、V4-54、V4-55）
8. 回归测试、性能优化与资源规范（V4-44 ~ V4-46、V4-66）

当前自动化测试按模块分布在 `tests/` 下的 `core`、`topology`、`openings`、`furniture`、`materials`、`landscape`、`exporters` 和 `viewer` 八个目录，共 50 个测试文件、206 个测试。运行 `npm run test` 会递归执行整个 `tests` 目录；运行 `npm run build` 可验证生产构建。

V4 的主要增量覆盖：家具吸附与高度修正、现代家具与厨房组件、窗帘参数化、建筑生成 Agent Skill、自定义天空盒、艺术海报、L 形楼梯、可控水景、双开门动画、材质与 UV 优化、WebP 资源、拆墙后的地板拓扑修复、户外低多边形家具，以及布艺材质法线等。
